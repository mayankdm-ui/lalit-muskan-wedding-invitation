LALIT & MUSKAN — MOBILE WEDDING INVITATION

Included:
- index.html — page structure
- style.css — mobile design + animations
- script.js — scratch-to-reveal, live countdown, gallery swipe/slider, selection UI, sound toggle and WhatsApp RSVP
- assets/ — supplied wedding assets plus rendered supplied PDF sections used where they preserve the exact artwork

REFERENCE / DESIGN BASIS
The supplied MP4 was used as the interaction reference: scroll through sections, floating sound control, scratch hearts, image/gallery browsing and RSVP interaction.
The supplied Wedding invite L and M PDF was used for the exact content/layout direction.

SCRATCH REVEAL
Scratch all three supplied hearts. Once each heart is more than roughly 52% scratched, the live countdown card appears.
The countdown targets 19 November 2026 at 00:00 IST, based on the invitation's Save the Date / ceremony date.

WHATSAPP
The form opens WhatsApp to +91 8638956610 with a pre-filled response. The visitor must press Send in WhatsApp; a normal website cannot silently send a WhatsApp message on the visitor's behalf.

GOOGLE MAPS
The GET DIRECTIONS button is linked to:
https://maps.app.goo.gl/55ZWTHQc8z7AJvVs8?g_st=iw

MUSIC
No music/audio file was supplied in the uploaded asset ZIP. The sound button and audio logic are included. To activate music, add a file named wedding-music.mp3 in assets/ and set the audio src in index.html to assets/wedding-music.mp3.

FONT NOTE
The design uses Times New Roman, Italianno, Judson and Inknut Antiqua. Italianno, Judson and Inknut Antiqua load from Google Fonts when internet is available; Times New Roman is the fallback serif.

RUN LOCALLY
1. Keep the folder structure unchanged.
2. Open index.html in Chrome/Edge.
3. For the most reliable local testing, serve the folder with any simple local server, e.g. VS Code Live Server.
